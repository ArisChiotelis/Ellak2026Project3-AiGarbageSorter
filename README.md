# Auto-Recycle
**Ένας αυτόματος κάδος διαλογής ανακυκλώσιμων με AI όραση (HuskyLens)**

## 1. Τι είναι
Το **Auto-Recycle** είναι ένα εκπαιδευτικό, αυτοματοποιημένο σύστημα διαλογής απορριμμάτων.  
Ο χρήστης τοποθετεί ένα αντικείμενο στον **placer**, η κάμερα **Gravity HuskyLens** το αναγνωρίζει και το κατηγοριοποιεί (π.χ. πλαστικό/μέταλλο/χαρτί). Στη συνέχεια, σύστημα μεταφοράς με **ροδέλες** μετακινεί το αντικείμενο και τα **push walls** το ωθούν στον σωστό κάδο συλλογής.  
(Περιγραφή/σύλληψη σύμφωνα με το project υλικό μας.)

## 2. Στόχος (γιατί το κάνουμε)
- Κατανόηση της **ανακύκλωσης** και της ανάγκης για σωστή διαλογή.
- Εισαγωγή σε **αυτοματισμούς** (αισθητήρες/ενεργοποιητές/ροή ελέγχου).
- Εισαγωγή στην **τεχνητή όραση** με πρακτικό, σχολικό τρόπο (HuskyLens).
- Συνεργασία ομάδας, σχεδιασμός, δοκιμές και βελτιώσεις (STEM).

## 3. Πώς λειτουργεί (Workflow)
1. **Placer**: ο χρήστης αφήνει το αντικείμενο στο σημείο εισόδου  
2. **HuskyLens**: αναγνώριση/κατηγοριοποίηση  
3. **Μεταφορά**: ενεργοποίηση ροδελών/ιμάντα και μετακίνηση αντικειμένου  
4. **Push wall**: ενεργοποίηση του σωστού ωθητήρα  
5. **Σωστός κάδος**: το αντικείμενο πέφτει στο αντίστοιχο δοχείο  
6. Επιστροφή σε κατάσταση **αναμονής**

## 5. Υλικά (Bill of Materials)
### Βασικά
- **Gravity HuskyLens** (AI Machine Vision Sensor)
- Μικροελεγκτής (π.χ. Arduino UNO / ESP32)
- Servo motors (για push walls) x2–3
- DC motor (για μεταφορά) x1
- Breadboard + καλώδια jumper
- Τροφοδοσία (5V/USB ή μπαταρίες/holder)
- Υλικά μακέτας (χαρτόνι/MDF/ξύλο), βίδες/δεματικά, κόλλα

### Προαιρετικά (για καλύτερη σταθερότητα)
- End-stop / microswitch (όριο θέσης)
- Βάση/οδηγοί για να “κάθεται” σωστά το αντικείμενο στη μεταφορά

## 8. Setup / Βήματα υλοποίησης (high level)
1. Στήσιμο μακέτας: placer → διάδρομος μεταφοράς → κάδοι
2. Τοποθέτηση HuskyLens ώστε να “βλέπει” σωστά το αντικείμενο στον placer
3. Εκπαίδευση/ρύθμιση HuskyLens (ανάλογα με το mode: object recognition κ.λπ.)
4. Σύνδεση servo για push walls και DC motor για μεταφορά
5. Έλεγχος: αναγνώριση → μεταφορά → push σωστός κάδος
6. Δοκιμές με διαφορετικά αντικείμενα και βελτίωση (σταθερότητα/σφάλματα)

## 9. Περιορισμοί & ρεαλισμός
- Η αναγνώριση εξαρτάται από **φωτισμό**, γωνία κάμερας και ομοιότητα αντικειμένων.
- Προβλέπεται διαδρομή “μη αναγνωρίσιμο” (reject / γενικός κάδος).
- Το project είναι εκπαιδευτικό: προτεραιότητα έχει η **κατανόηση της ροής** και όχι “βιομηχανική ακρίβεια”.
